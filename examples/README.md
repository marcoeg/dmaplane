# Examples

Progressive demos that build on each subsystem.

| Directory | Description |
|-----------|-------------|
| `misc/` | `dma_explorer`, `dma_sweep`, `trace_explorer` |
| `netshare/` | Cross-machine RDMA host path (`sender` / `receiver` via rdma_cm) |
| `streamer/` | Weight-streaming TUI (`weight_streamer_tui` — ncurses) |
| `gpu_rdma/` | Cross-machine GPU VRAM over RDMA (`gpu_sender` / `gpu_receiver`) |
| `kvcache/` | KVCache WRITEIMM pipeline, C sender/receiver, Python inference servers |
